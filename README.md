## Integrations (how I use them)

- Supabase (Database)
  - Postgres-based hosted database used for app data, realtime features, and file storage.
  - Good for quick prototypes and production apps where I want a managed Postgres + realtime layer.
  - Docs: https://supabase.com/docs

- Supabase Authentication
  - Email/password, OAuth sign-in flows, session management, and role-based access control for web apps.
  - Client libraries: @supabase/supabase-js (frontend), or server-side calls from Laravel via HTTP.
  - Docs: https://supabase.com/docs/guides/auth

- PayPal Integration
  - Implemented as a payments option in some management systems:
    - Client-side: PayPal JS SDK (checkout buttons, order creation).
    - Server-side: capture and verify payments with PayPal REST API or PayPal PHP SDK in Laravel (create orders, capture payments, validate webhooks).
  - Useful for subscriptions, one-time payments, or donation flows.
  - Docs: https://developer.paypal.com

If you want code examples, here are quick pointers:
- React + Supabase auth: use createClient() from @supabase/supabase-js, then auth.signInWithPassword / auth.signUp.
- Laravel + PayPal: create server endpoints to call PayPal Orders API, verify webhook signatures before granting access.
Tell me which stack (Laravel or React) you want examples for and I’ll add short code snippets.
